# Architecture and construction software demos

I build browser tools for exploring design and construction decisions. These five MIT-licensed projects cover how people move through a showroom, how furniture fits in a room, how a panorama communicates a space, and how quantities and progress translate into costs.

| Project | Try it | Source |
| --- | --- | --- |
| **Showroom Pulse** · Compare visitor routes and zone dwell across an illustrative showroom. | [Live demo](https://ameer93emad-dev.github.io/ai-showroom-analytics/) | [Repository](https://github.com/ameer93emad-dev/ai-showroom-analytics) |
| **BuildCost** · Price a bill of quantities with separate material, labor and equipment rates. | [Live demo](https://ameer93emad-dev.github.io/construction-boq-tool/) | [Repository](https://github.com/ameer93emad-dev/construction-boq-tool) |
| **Arch360** · Inspect local panoramic renders and transfer a tour as JSON. | [Live demo](https://ameer93emad-dev.github.io/architecture-virtual-tour/) | [Repository](https://github.com/ameer93emad-dev/architecture-virtual-tour) |
| **SpacePlan** · Arrange furniture on a half-meter grid and compare footprints. | [Live demo](https://ameer93emad-dev.github.io/architecture-space-planner/) | [Repository](https://github.com/ameer93emad-dev/architecture-space-planner) |
| **BuildTrack** · Explore budget-weighted progress and earned-value indicators. | [Live demo](https://ameer93emad-dev.github.io/construction-project-dashboard/) | [Repository](https://github.com/ameer93emad-dev/construction-project-dashboard) |

The showroom journeys, estimate rates and project schedule use demonstration data. The tour viewer accepts your own panoramas, and the planner starts with an empty room. Each repository includes a screenshot, a short walkthrough and the assumptions behind its calculations or visualization.
